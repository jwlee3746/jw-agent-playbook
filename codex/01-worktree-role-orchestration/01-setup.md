# 01 · 준비

작업장을 만들기 전에 기준 저장소가 깨끗한지 확인한다.

## 갖춰야 할 것

- **git worktree를 쓸 수 있는 저장소** — 이미 커밋이 하나 이상 있어야 한다
- **하네스** — Codex Desktop, 또는 터미널에서 세션을 여러 개 띄울 수 있는 CLI 에이전트
- **검증 스크립트** — 이 구조의 판정은 전부 스크립트 통과 여부에 걸려 있다. 통과/실패를 기계가 말해주지 못하면 나머지가 무의미해진다. 없으면 [02](02-work-order.md)에서 먼저 만든다

검증 스크립트는 외부 의존성 없이 도는 게 좋다. 역할마다 다른 작업장에서 실행되므로, 환경이 조금만 달라도 결과가 갈리면 판정을 믿을 수 없다.

## 확인

```bash
cd <repo>
git switch master          # 또는 main. 이 문서는 master로 쓴다
git status                 # 반드시 clean 이어야 한다
git worktree list          # 남아 있는 작업장이 있는지 확인
```

`git status`가 깨끗하지 않으면 먼저 정리한다. 커밋되지 않은 변경이 있는 상태에서 worktree를 만들면, 어느 작업장의 결과인지 나중에 구분할 수 없다.

`git worktree list`에 이전 실행의 작업장이 남아 있으면 [06](06-approve-cleanup.md)의 정리 절차로 회수한다.

## 흔한 실패

- **기준 branch를 헷갈린다** — 저장소마다 `master`인지 `main`인지 다르다. 아래 스텝의 명령을 그대로 복사하기 전에 확인한다
- **작업장을 저장소 안에 만든다** — `../wt-backend`처럼 저장소 바깥 경로를 쓴다. 안에 만들면 그 디렉토리가 자기 자신의 변경으로 잡힌다
