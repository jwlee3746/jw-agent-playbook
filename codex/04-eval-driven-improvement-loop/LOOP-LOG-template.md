# LOOP LOG — 템플릿

프로젝트에 복사해 쓴다. 매 단계 프롬프트의 `<루프 기록>`이 이 파일이다.

[02의 MEMORY](../02-aorr-worker-verifier-loop/MEMORY-template.md)와 같은 역할이고 같은 길이 규칙을 따른다 — **항목당 한 줄, 원시 로그·전체 출력·diff를 넣지 않는다.** 회차 상세는 별도 평가 결과 파일로 보낸다.

02와 다른 것은 회차가 쌓인다는 점이다. **최근 5회차만 본문에 두고 나머지는 요약 표로 접는다.** 이 파일이 길어지면 매 회차 컨텍스트를 잡아먹어서 원래 목적을 잃는다.

## Guardrails

- 골든셋·기대값·rubric·채점 코드 수정 금지 (D 트랙 승인 제외)
- holdout은 5단계에서만, 총점·유형별 집계만. 개별 케이스 열람 금지
- few-shot에 holdout 유래 예제 투입 금지
- 한 회차에 트랙 하나, 변경 하나
- 게이트 실패는 되돌리기. 통과할 때까지 고치지 않음
- <프로젝트별 금지 사항>
