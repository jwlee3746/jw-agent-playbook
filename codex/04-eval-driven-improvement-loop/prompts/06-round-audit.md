# 6 · 회차 감사 — 템플릿

N회차마다 **루프 자체**를 점검한다. 개별 회차 게이트가 구조적으로 잡지 못하는 것들이 여기서 잡힌다.

## 프롬프트

```
[6 - 회차 감사 · 회차 <N>까지]

Gatekeeper가 단독으로 수행한다. 아무것도 수정하지 않는다.

읽을 것: <루프 기록> 전체, <분류표 파일>

여섯 가지를 확인하고 각각에 대해 수치와 판단을 낸다.

1. dev–holdout 격차 추이
   회차별로 (dev 점수 - holdout 점수)를 나열해.
   격차가 회차를 거치며 벌어지는 추세인지 판단해.

2. 회차당 개선폭 추이
   통과한 회차의 개선폭을 시간순으로 나열해.
   줄어드는 추세인지 판단해.

3. 지문별 개입 횟수
   같은 지문에 3회 이상 개입한 것을 모두 나열해.
   각각에 대해 현재 트랙과, 다른 트랙일 가능성을 적어.

4. D 트랙 제안 빈도
   회차당 D 트랙 제안 건수를 나열해.
   승인된 것과 기각된 것의 비율도 함께.

5. 프롬프트 길이 추이
   회차별 시스템 프롬프트 길이(토큰 또는 문자)를 나열해.
   그리고 현재 프롬프트에서 서로 충돌하거나 중복되는 지시가
   있으면 짚어.

6. holdout 개봉 횟수 대 회차 수
   개봉 횟수 / 전체 회차 수를 계산해.

각 항목에 대해 판단과 대응을 표로 보고해:
| 신호 | 수치 | 판단 | 대응 |

7. Acceptance 대조
   <루프 기록>의 종료 조건과 현재 holdout 점수를 대조해.
   충족했으면 그 사실을 먼저 보고해.

마지막에 셋 중 하나를 권고하고 근거를 위 항목에서 인용해:
  계속      — 루프를 더 돌린다
  1단계 복귀 — 평가가 볼 수 있는 것을 다 짰다. 새 실패 유형을 찾는다
  종료      — Acceptance를 충족했다

**권고만 한다.** 상태를 AUDIT_DECISION_REQUIRED로 두고 멈춰.
어느 쪽으로 갈지는 사람이 정한다.

수정하지 마. 다음 회차를 시작하지 마.
```

## 신호와 대응

| 신호 | 무엇을 뜻하나 | 대응 |
|---|---|---|
| **dev–holdout 격차가 벌어진다** | dev 과적합 | 루프를 멈춘다. dev를 갱신하거나 1단계로 |
| 회차당 개선폭이 줄어든다 | 현재 평가로 짜낼 것을 다 짰다 | **1단계를 다시 돈다.** 새 실패 유형을 찾을 시점 |
| 같은 지문에 3회 이상 개입 | 트랙 배정이 틀렸다 | 트랙 재배정. 대개 P → C 또는 D |
| **D 트랙 제안이 잦다** | 골든셋 품질 문제이거나, 에이전트가 쉬운 길을 찾는 중 | 제안을 모아 사람이 한 번에 판정 |
| 프롬프트 길이가 계속 는다 | 지시가 쌓여 충돌하는 중 | 프롬프트 정리 회차를 따로 돈다 |
| **개봉 횟수가 회차 수에 근접** | holdout이 사실상 dev가 됐다 | 새 holdout을 떼거나 루프를 멈춘다 |

## 주의

### 1번과 6번이 이 단계의 이유

나머지 넷은 회차를 보다 보면 사람도 눈치챈다. 1번과 6번은 **회차 하나만 봐서는 절대 안 보인다.** 게이트는 매 회차 통과하는데 루프 전체가 망가지는 경로가 정확히 이 둘이다.

특히 6번은 조용하다. 게이트마다 holdout을 여는 것은 규칙대로 하는 일이고, 매번 정당하다. 그런데 열 때마다 holdout 정보가 조금씩 루프로 새어 들어간다 — 어느 회차가 holdout에서 떨어졌는지가 다음 회차의 선택에 영향을 주기 때문이다. **횟수 자체를 세지 않으면 언제 넘었는지 알 수 없다.**

### 개선폭이 줄어드는 것은 실패가 아니다

2번을 "루프가 잘 안 돌아간다"로 읽으면 안 된다. **현재 평가가 볼 수 있는 개선을 다 했다는 뜻**이고, 정상적인 수렴이다.

이때 필요한 것은 더 많은 회차가 아니라 1단계다. 새 실패 유형을 찾아 평가에 넣어야 루프가 볼 수 있는 것이 늘어난다. 회차를 계속 돌리면 남는 것은 과적합뿐이다.

### 마지막 질문

프롬프트가 **"계속 돌려도 되는가"를 명시적으로 묻는 것**이 이 단계의 결론이다. 여섯 항목을 나열하고 끝내면 사람이 종합해야 하고, 대개 종합하지 않고 다음 회차를 돌린다.

판단을 하나로 강제하면 근거가 표에 남는다.
