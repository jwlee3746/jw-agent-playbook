## 용도

프로젝트 루트나 `~/.claude/CLAUDE.md`에 넣어 에이전트의 기본 행동을 교정할 때 쓴다.

하네스 오케스트레이션 설계가 아니라 **단일 에이전트의 행동 규칙**이라, 이 레포의 다른 항목들과 층위가 다르다. 여러 에이전트를 엮는 설계와는 별개로, 그 아래 깔리는 바닥 규칙에 해당한다.

속도보다 신중함에 치우쳐 있어 사소한 작업에는 과하다.

네 원칙은 이렇다.

1. **Think Before Coding** — 넘겨짚지 말고, 헷갈리는 걸 숨기지 말고, 트레이드오프를 드러낸다
2. **Simplicity First** — 문제를 푸는 최소한의 코드. 미리 만들어두는 것은 없다
3. **Surgical Changes** — 고쳐야 할 것만 고치고, 치우는 건 내가 어지른 것만
4. **Goal-Driven Execution** — 완료 조건을 먼저 정하고 검증될 때까지 돈다

가장 판정하기 쉬운 기준은 3번이다. 바뀐 모든 줄이 사용자 요청으로 곧바로 거슬러 올라가야 한다.
