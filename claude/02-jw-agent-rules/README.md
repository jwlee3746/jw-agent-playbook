# 02 · 코드 없는 레포용 에이전트 규칙

**한 줄**: [01](../01-karpathy-claude-md/)의 네 원칙 중 하나만 남겨 넓히고, 외부 자료를 다루는 레포에 필요한 규칙 하나를 더한 규칙 셋.
**출처**: 자작 — 01에서 파생
**상태**: 실험 중

## 구성

| 파일 | 역할 |
|---|---|
| [`CLAUDE-kr.md`](CLAUDE-kr.md) | 규칙 본문. 다른 문서 저장소에 복사해 쓸 때 이 파일을 가져가 `CLAUDE.md`로 저장한다 |

파일명에 `-kr`을 붙인 이유는 언어 표시가 전부가 아니다. 하위 디렉토리에 `CLAUDE.md`를 그대로 두면 이 경로에서 작업할 때 Claude Code가 그걸 읽어 **카탈로그에 보관 중인 규칙이 실제로 적용된다.** 접미사가 붙으면 로드되지 않는다.

레포 루트의 `CLAUDE.md`는 지금 실제로 적용 중인 규칙이라 `.gitignore`에 넣어 로컬에서만 관리한다. 커밋되는 것은 이 항목 안의 사본이다.

## 용도

실행되는 코드가 없고 문서·설정·레퍼런스를 모으는 저장소에서 쓴다. 하네스 오케스트레이션 설계가 아니라 단일 에이전트의 바닥 규칙이라는 점은 01과 같다.

코드가 있는 레포에는 쓰지 않는다. 아래 표에서 제외한 세 원칙을 다시 가져와야 한다.

## 전제

- 하네스 / 모델: Claude Code
- 대상 레포의 성격: **테스트로 완료를 판정할 수 없는 문서 저장소**. 아래 취사선택은 전부 이 전제에서 나온다
- 프로젝트별 지침을 대체하지 않고 그 위에 얹어서 씀

## 01에서 무엇을 가져오고 무엇을 버렸나

| 01의 원칙 | 결정 | 근거 |
|---|---|---|
| Think Before Coding | **채택 + 확장** | 완료 조건으로 걸러낼 수 없는 만큼 시작 전에 거르는 몫이 커진다. 되돌리기 비용, 기존 규칙과의 충돌, 중복 배치, 미리 만드는 빈 껍데기 — 네 항목을 덧붙였다 |
| Simplicity First | 제외 | 코드를 쓰지 않아 과설계·부풀린 추상화 위험이 낮다 |
| Surgical Changes | 제외 | 리팩터링할 코드가 없다 |
| Goal-Driven Execution | 제외 | 테스트가 없어 "테스트를 쓰고 통과시킨다" 형태의 완료 조건을 만들 수 없다. 억지로 넣으면 지켜지지 않는 규칙만 남는다 |
| — | **추가**: 빌려오기 전에 검증한다 | 이 레포가 하는 일이 남의 작업을 모으는 것이라, 원문에 없던 축이 필요하다 |

결과적으로 01의 네 원칙 중 하나만 남았다. 남은 하나도 그대로가 아니라 이 레포의 실패 유형에 맞춰 넓혔다. **유명한 규칙 셋을 그대로 가져오는 것이 기본값이 아니라는 게 이 항목의 요지다.**

추가한 규칙의 요지는 셋이다 — 먼저 검색할 것, **검색 요약이 아니라 원본을 열 것**, 유명한 것과 여기에 맞는 것을 구분할 것.

## 결과

2026-08-02, 이 레포의 구조를 잡고 첫 항목들을 추가하는 한 세션에서 관찰했다. 표본이 하나뿐이라 `실험 중`으로 둔다.

- **잘 된 점 (규칙 1)**: 번호 체계, 외부 항목의 배치, 라이선스 처리 — 세 번 모두 구현 전에 질문이 나왔다. 배치를 먼저 물어본 덕분에 나중에 디렉토리를 갈아엎는 일이 없었다.
- **잘 된 점 (규칙 2)**: 라이선스 확인에서 두 번 걸렸다. 검색 요약은 원작을 MIT라고 했으나 레포에 LICENSE 파일이 없었고, 반대로 GitHub API는 라이선스 없음으로 보고했으나 원작 README 본문에는 MIT가 명시돼 있었다. 요약만 봤으면 양쪽 다 틀렸다.
- **실패한 점**: 규칙 2를 따르는 과정에서 라이선스 판단이 한 번 번복됐다. 결론은 맞았지만, 원본을 끝까지 읽고 결론을 냈으면 번복이 없었다. "원본을 연다"에 **끝까지 읽는다**가 빠져 있다.
- **확장의 근거**: 규칙 1에 덧붙인 네 항목은 전부 이 세션에서 실제로 필요했던 것이다. 번호 재사용 금지(되돌리기 비용), 템플릿과 "빈 파일 만들지 않기" 규칙의 충돌, README 형식이 두 곳에 중복된 것, 지금 만들면 빈 채로 남을 `shared/` — 네 가지가 각각 한 항목씩에 대응한다.
- **다음에 바꾼다면**: 규칙 2에 "끝까지 읽는다"를 넣을지 검토한다. 다만 규칙이 길어지면 지켜지지 않으므로 한 세션 더 관찰하고 정한다.
