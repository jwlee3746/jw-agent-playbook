# jw-agent-playbook

에이전트 하네스(harness)를 만들 때 반복적으로 꺼내 쓰는 프롬프트, 전략, 세팅을 모아두는 저장소입니다.

매번 처음부터 다시 설계하지 않기 위한 개인 레퍼런스이자, 검증된 패턴을 남들과 공유하기 위한 공간입니다.

## 구조

| 디렉토리 | 내용 |
|---|---|
| `prompts/` | 시스템 프롬프트, 역할별 프롬프트, 프롬프트 조각(fragment) |
| `strategies/` | 오케스트레이션 패턴 — fan-out, 검증 루프, 판정 패널, 재시도/폴백 설계 |
| `settings/` | 하네스 설정 — 모델·토큰·툴 구성, 권한 정책, 하네스별 config |

## 항목 추가 규칙

각 항목은 파일 하나로 관리하고, 상단에 다음을 남깁니다.

- **용도** — 어떤 상황에서 쓰는가
- **전제** — 어떤 하네스/모델/툴 구성을 가정하는가
- **결과** — 실제로 써봤을 때 잘 된 점과 실패한 점

마지막 항목이 핵심입니다. 잘 됐던 것만 모으면 왜 그 선택을 했는지 6개월 뒤에 알 수 없습니다.

## 상태

초기 단계입니다. 구조는 내용이 쌓이면서 바뀔 수 있습니다.
